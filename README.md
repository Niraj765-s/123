# 123
robot kinematics

Simple 3-DOF robot forward kinematics in MATLAB/Octave.

## Files
- `forward_kinematics_3dof.m` - Computes homogeneous transform `T` and end-effector position.
- `test_forward_kinematics_3dof.m` - Runs basic checks and prints pass/fail.

## Dependencies
- MATLAB (no extra toolbox required), or
- GNU Octave (compatible runtime)

## Run test
In MATLAB or Octave, from repository root:

```matlab
test_forward_kinematics_3dof
```

Expected success output includes:
- `Running test_forward_kinematics_3dof...`
- `All tests passed. Work done: code ran successfully.`
